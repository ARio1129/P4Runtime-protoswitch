チュートリアルでの確認手順

STEP 04 / STEP 05
  1. STEP 03：4件のLPMエントリを登録10.0.0.0/30 → port1（s2）10.0.0.4/30 → port2（s3）10.0.0.8/30 → port3（s4）10.0.0.12/30 → port4（h12）
  2. STEP 04：異なるL2スイッチ間の通信mininet> h1 ping -c 3 h5通常は h1 → s2 → s1 → s3 → h5 を経由する。
  3. STEP 05：同じL2スイッチ内の通信mininet> h1 ping -c 3 h2宛先MACが学習済みなら h1 → s2 → h2。未学習時はs2から複数リンクに転送される可能性があり、観測ログで確認できる。

パケット型アイコンの移動は観測したICMPのリンク通過情報に基づく低速再生です。描画の時間は実際のネットワーク遅延を表しません。画面からLPMテーブルの登録・変更は行いません。

ライブ監視ではDockerコンテナ内の各スイッチインターフェースを読み取り、Mac側の127.0.0.1で表示します。これはネットワークトポロジーを変更しません。ICMP Echo Request / Replyを対象にしており、ARPやICMP以外のフレームは描画しません。
